RTL SUPPORT
===========

CRITICAL: Full right-to-left language support
- Auto-detection from dir="rtl" attribute
- Complete UI mirroring
- Text alignment and direction
- Badge positioning adjustment
- Icon and button placement
- Logical properties throughout

ENABLING RTL
------------
Set dir attribute on component:

<web-multiselect dir="rtl">
  <option value="1">خيار 1</option>
  <option value="2">خيار 2</option>
  <option value="3">خيار 3</option>
</web-multiselect>

Or on parent element:
<div dir="rtl">
  <web-multiselect>
    <option value="1">אפשרות 1</option>
    <option value="2">אפשרות 2</option>
  </web-multiselect>
</div>

Component auto-detects and mirrors UI

AUTO-DETECTION
--------------
Component checks for dir="rtl":

1. On component itself
2. On parent elements (bubbles up)
3. On <html> element

Example (page-wide RTL):
<!DOCTYPE html>
<html dir="rtl" lang="ar">
  <body>
    <web-multiselect>
      <!-- Automatically in RTL mode -->
    </web-multiselect>
  </body>
</html>

UI MIRRORING
------------
Automatic RTL adjustments:

Text alignment:
- Right-aligned by default
- Text flows right-to-left
- Arabic/Hebrew script rendering

Layout:
- Icons move to right side
- Badges flow right-to-left
- Dropdown opens correctly
- Chevron/arrows flip

Removal buttons:
- Badge X button on left
- Clear all button positioning

BADGE POSITIONING
-----------------
Badge position adapts for RTL:

LTR:
- bottom: Below input
- top: Above input
- left: To the left of input
- right: To the right of input

RTL (mirrored):
- bottom: Below input (same)
- top: Above input (same)
- left: To the RIGHT of input (flipped)
- right: To the LEFT of input (flipped)

Example:
<web-multiselect
  dir="rtl"
  badges-position="right">
  <!-- Badges appear on LEFT in RTL -->
</web-multiselect>

LOGICAL PROPERTIES
------------------
Component uses CSS logical properties:

Instead of:
- margin-left, margin-right
- padding-left, padding-right
- left, right

Uses:
- margin-inline-start, margin-inline-end
- padding-inline-start, padding-inline-end
- inset-inline-start, inset-inline-end

This ensures automatic RTL support

CHECKBOX ALIGNMENT
------------------
Checkboxes mirror correctly:

LTR: Checkbox on left of label
RTL: Checkbox on right of label

Controlled via CSS logical properties

CSS VARIABLES RTL
-----------------
Margins/padding adapt automatically:

LTR variables:
--ml-option-padding-h: 1rem

Becomes in RTL:
padding-inline-start: 1rem  /* Right */
padding-inline-end: 1rem    /* Left */

Custom RTL styling:
<style>
  web-multiselect[dir="rtl"] {
    --ml-custom-rtl-spacing: 0.5rem;
  }
</style>

INTERNATIONALIZATION
--------------------
Combine RTL with i18n:

<web-multiselect
  dir="rtl"
  lang="ar"
  search-placeholder="بحث..."
  empty-message="لا توجد نتائج"
  loading-message="جاري التحميل...">
</web-multiselect>

Custom counter for RTL languages:
select.getCounterCallback = (count) => {
  const lang = select.getAttribute('lang');

  if (lang === 'ar') {
    return count === 1 ? 'عنصر واحد' : `${count} عناصر`;
  }

  return `${count} selected`;
};

DYNAMIC RTL SWITCHING
---------------------
Change direction at runtime:

const select = document.querySelector('web-multiselect');

// Switch to RTL
select.setAttribute('dir', 'rtl');

// Switch to LTR
select.setAttribute('dir', 'ltr');

// Or toggle
const currentDir = select.getAttribute('dir');
select.setAttribute('dir', currentDir === 'rtl' ? 'ltr' : 'rtl');

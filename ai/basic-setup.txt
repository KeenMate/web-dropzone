BASIC SETUP
===========

CRITICAL: This is a Web Component (Custom Element) with Shadow DOM
- Works in vanilla HTML, React, Vue, Svelte, Angular, etc.
- Can be used declaratively (HTML) or programmatically (JavaScript)
- Styles are encapsulated in Shadow DOM
- SSR-safe (won't crash during server-side rendering)

INSTALLATION
------------
npm install @keenmate/web-multiselect

# Or yarn
yarn add @keenmate/web-multiselect

# Or pnpm
pnpm add @keenmate/web-multiselect

DECLARATIVE USAGE (NO JAVASCRIPT)
----------------------------------
Simplest way to get started:

<!-- 1. Import in HTML -->
<script type="module">
  import '@keenmate/web-multiselect';
</script>

<!-- 2. Use the component -->
<web-multiselect>
  <option value="js">JavaScript</option>
  <option value="ts" selected>TypeScript</option>
  <option value="py">Python</option>
  <option value="java">Java</option>
</web-multiselect>

With groups:

<web-multiselect>
  <optgroup label="Frontend">
    <option value="react">React</option>
    <option value="vue">Vue</option>
  </optgroup>
  <optgroup label="Backend">
    <option value="node">Node.js</option>
    <option value="python">Python</option>
  </optgroup>
</web-multiselect>

PROGRAMMATIC USAGE (JAVASCRIPT)
--------------------------------
More control and dynamic data:

// 1. Import
import '@keenmate/web-multiselect';

// 2. Create element
const select = document.createElement('web-multiselect');

// 3. Set options
select.options = [
  { value: 'js', label: 'JavaScript' },
  { value: 'ts', label: 'TypeScript' },
  { value: 'py', label: 'Python' }
];

// 4. Add to DOM
document.body.appendChild(select);

Or query existing element:

const select = document.querySelector('web-multiselect');
select.options = [
  { value: 1, label: 'Option 1' },
  { value: 2, label: 'Option 2' }
];

CUSTOM DATA ATTRIBUTES
----------------------
Map your data structure using member attributes:

<web-multiselect
  value-member="id"
  display-value-member="name"
  icon-member="emoji"
  group-member="category">
</web-multiselect>

<script>
  const select = document.querySelector('web-multiselect');
  select.options = [
    { id: 1, name: 'Apple', emoji: '🍎', category: 'Fruits' },
    { id: 2, name: 'Banana', emoji: '🍌', category: 'Fruits' },
    { id: 3, name: 'Carrot', emoji: '🥕', category: 'Vegetables' }
  ];
</script>

IMPORTANT: Declarative HTML parsing uses data- prefixed attributes:
<option value="1" data-icon="🍎">Apple</option>

SINGLE-SELECT MODE
------------------
Set multiple="false" for single selection:

<web-multiselect multiple="false">
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
</web-multiselect>

Or programmatically:
select.multiple = false;

GETTING SELECTED VALUES
------------------------
Multiple ways to access selections:

// Get selected option objects
const selected = select.getSelected();
console.log(selected); // [{ value: 1, label: 'Option 1' }, ...]

// Get values only
const values = select.getValue();
console.log(values); // [1, 2, 3] or single value if multiple="false"

// Listen to change event
select.addEventListener('change', (e) => {
  console.log('Selected:', e.detail.selectedOptions);
  console.log('Values:', e.detail.selectedValues);
});

SETTING INITIAL VALUES
----------------------
Declarative (use selected attribute):

<web-multiselect>
  <option value="1" selected>Option 1</option>
  <option value="2">Option 2</option>
  <option value="3" selected>Option 3</option>
</web-multiselect>

Or with initial-values attribute:

<web-multiselect initial-values='["1", "3"]'>
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
  <option value="3">Option 3</option>
</web-multiselect>

Programmatic:

// Method 1: Set values by IDs
select.setSelected([1, 3]);

// Method 2: Set during initialization
select.options = [
  { value: 1, label: 'Option 1', selected: true },
  { value: 2, label: 'Option 2' },
  { value: 3, label: 'Option 3', selected: true }
];

SEARCH CONFIGURATION
--------------------
Control search behavior:

<web-multiselect
  enable-search="true"               <!-- Enable/disable search -->
  search-placeholder="Type to search..."
  min-search-length="2"              <!-- Minimum chars to trigger -->

</web-multiselect>

Disable search:
<web-multiselect enable-search="false"></web-multiselect>

DISABLED OPTIONS
----------------
Mark options as disabled:

Declarative:
<option value="1" disabled>Disabled Option</option>

Programmatic:
select.options = [
  { value: 1, label: 'Available' },
  { value: 2, label: 'Disabled', disabled: true }
];

GROUPING OPTIONS
----------------
Organize options into groups:

Declarative:
<web-multiselect allow-groups="true">
  <optgroup label="Fruits">
    <option value="apple">Apple</option>
    <option value="banana">Banana</option>
  </optgroup>
  <optgroup label="Vegetables">
    <option value="carrot">Carrot</option>
  </optgroup>
</web-multiselect>

Programmatic:
select.options = [
  { value: 1, label: 'Apple', group: 'Fruits' },
  { value: 2, label: 'Banana', group: 'Fruits' },
  { value: 3, label: 'Carrot', group: 'Vegetables' }
];

DROPDOWN POSITIONING
--------------------
Configure dropdown placement:

<web-multiselect
  max-height="20rem"                 <!-- Max dropdown height -->
  dropdown-min-width="200px"         <!-- Min dropdown width -->
  lock-placement="false">            <!-- Allow repositioning -->
</web-multiselect>

Dropdown uses Floating UI for smart positioning:
- Auto-flips when near viewport edges
- Respects scroll boundaries
- Adjusts for available space

Control checkbox display:

EMPTY STATES

FRAMEWORK INTEGRATION
---------------------
React:
import '@keenmate/web-multiselect';

function MyComponent() {
  const selectRef = useRef(null);

  useEffect(() => {
    const select = selectRef.current;
    select.options = [...];

    const handleChange = (e) => console.log(e.detail);
    select.addEventListener('change', handleChange);

    return () => select.removeEventListener('change', handleChange);
  }, []);

  return <web-multiselect ref={selectRef} />;
}

Vue:
<template>
  <web-multiselect
    ref="select"
    @change="handleChange">
  </web-multiselect>
</template>

<script setup>
import '@keenmate/web-multiselect';
import { onMounted, ref } from 'vue';

const select = ref(null);

onMounted(() => {
  select.value.options = [...];
});

const handleChange = (e) => {
  console.log(e.detail.selectedOptions);
};
</script>

Svelte:
<script>
  import '@keenmate/web-multiselect';
  import { onMount } from 'svelte';

  let select;

  onMount(() => {
    select.options = [...];
  });

  function handleChange(e) {
    console.log(e.detail.selectedOptions);
  }
</script>

<web-multiselect
  bind:this={select}
  on:change={handleChange}>
</web-multiselect>

SSR / SERVER-SIDE RENDERING
---------------------------
Safe to import during SSR (won't crash):

✅ import '@keenmate/web-multiselect';  // Safe

Component only works in browser:
- Needs DOM, Shadow DOM, browser APIs
- Will not render during SSR
- Hydrates normally on client

For SSR frameworks (Next.js, Nuxt, SvelteKit):
- Import is safe
- Component renders only on client
- No special wrapper needed

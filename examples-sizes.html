📏 Sizes & Fonts

Control dimensions and typography with --dz-rem scaling and custom fonts

The --dz-rem sizing unit

Every internal dimension is expressed as calc(N * var(--dz-rem)). Change --dz-rem once and the whole component scales proportionally — no per-variable overrides needed.

Defaults
  • --dz-rem: 10px (so 1.4 * --dz-rem = 14px)
  • Pure-Admin theming: set --dz-rem: 1rem with html { font-size: 10px }
  • Compact: 8px · Large: 12px · XL: 15px

Global scaling with --dz-rem

The same dropzone at four different scales — same markup, only the --dz-rem CSS variable differs.

Compact (80%)

--dz-rem: 8px

Default (100%)

--dz-rem: 10px

Large (120%)

--dz-rem: 12px

Extra Large (150%)

--dz-rem: 15px

<!-- One variable scales everything -->
<web-dropzone style="--dz-rem: 12px;"></web-dropzone>

Per-variable overrides

For surgical changes, override individual CSS variables instead of --dz-rem.

web-dropzone {
    --dz-dropzone-text-font-size: 18px;
    --dz-dropzone-icon-size: 60px;
    --dz-dropzone-padding: 40px;
}

Custom fonts via --dz-font-family

The shadow DOM inherits the font set on the host. Set font-family directly or via --dz-font-family.

<!-- Either style attribute or CSS rule works -->
<web-dropzone style="font-family: 'Inter', sans-serif;"></web-dropzone>

<!-- Or with the dedicated variable -->
web-dropzone { --dz-font-family: 'Inter', sans-serif; }

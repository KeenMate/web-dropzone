🎨 Base Variables

Theme-designer typography and color integration with --base-* variables

What --base-* variables are

The KM web-component family shares a small set of theming variables prefixed --base-*. These are read by web-dropzone, web-multiselect, web-daterangepicker, and others, so when you set them on a parent element all of those components pick up the same theme.

Contract
  • Typography: --base-font-family, --base-font-size-xs|sm|base|lg (unitless multipliers), --base-font-weight-normal|medium|semibold
  • Colors: --base-accent-color[-hover|-active|-light], --base-text-color-1..4, --base-text-on-accent, --base-border-color, --base-primary-bg[-hover], --base-input-background, --base-success-color, --base-danger-color, --base-warning-color
  • Radii: --base-border-radius-sm|md|lg (unitless multipliers)

Pair with web-multiselect / web-daterangepicker

Apply --base-* on a high-level element (:root, your app shell, a theme container) and every KM component below inherits the same look.

:root {
    --base-accent-color: #10b981;
    --base-border-color: #d1fae5;
    --base-font-family: 'Inter', sans-serif;
    --base-font-size-sm: 1.4;
    --base-border-radius-md: 0.8;
}

/* All three pick up the same theme: */
<web-dropzone></web-dropzone>
<web-multiselect></web-multiselect>
<web-daterangepicker></web-daterangepicker>

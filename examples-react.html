React integration

A React component subscribes to a headless <web-dropzone> store via useEffect + files-changed, then renders its own JSX file list with full pause / resume / retry control.

Why headless mode unlocks React patterns

React expects to own the DOM it manages. With mode="headless" the dropzone steps back: it holds FileState[], dispatches events, and lets your component own the rendering. The native <web-dropzone-picker> satellite is still used as the drop surface, because re-implementing drag-and-drop in React would mean re-implementing a feature web-dropzone already ships.

Pattern
  • One useRef on the store element, one useEffect attaches the listener + upload callback.
  • useState holds the file array; the files-changed handler replaces it whole (the event is rAF-coalesced so this is cheap).
  • Per-row actions call store.pauseFile(id) / resumeFile / retryFile — the next event tick re-renders.

This demo uses htm for tagged-template JSX so the page works without a build step. With Babel or a real bundler you'd write the same code in regular JSX.

Heads-up: htm passes attribute names through verbatim, so you still write className (not class) and onClick (not onclick) — anything React expects. class is silently dropped by React, which means CSS classes vanish and styled elements like the progress bar end up invisible.

CSS transitions on the progress bar: avoid transition: width Xms on the bar fill. files-changed fires ≈ 60 Hz during an upload, so a 180 ms transition makes the bar lag the numeric % by ~11 frames — looks like the bar is barely moving while the text shoots ahead. Drive the width directly from a CSS custom property on the row and skip the transition; React's per-event commits already give you smooth motion.

Live demo

The React tree below renders the picker, list, and a toolbar with pause all / resume all / retry all / clear. Drop a few files and watch React re-render on every coalesced files-changed event.

The whole component (htm flavour)

import React, { useEffect, useRef, useState } from 'https://esm.sh/react@18'
import { createRoot } from 'https://esm.sh/react-dom@18/client'
import htm from 'https://esm.sh/htm@3'
const html = htm.bind(React.createElement)

function Uploader() {
    const storeRef = useRef(null)
    const [files, setFiles] = useState([])

    useEffect(() => {
        const store = storeRef.current
        store.uploadFileCallback = simulateUpload({ durationMs: 4000 })
        const onChange = (e) => setFiles(e.detail.files)
        store.addEventListener('files-changed', onChange)
        return () => store.removeEventListener('files-changed', onChange)
    }, [])

    const rowAction = (f) => {
        const s = storeRef.current
        if (f.status === 'uploading') return s.pauseFile(f.id)
        if (f.status === 'paused')    return s.resumeFile(f.id)
        if (f.status === 'error')     return s.retryFile(f.id)
    }

    return html`
        <web-dropzone ref=${storeRef} id="rx-store" mode="headless" multiple max-file-count="6"></web-dropzone>
        <web-dropzone-picker for="rx-store" selector-appearance="card" label="Drop files for React"></web-dropzone-picker>
        ${files.length === 0
            ? html`<div className="rx-empty">No files yet</div>`
            : html`<div className="rx-list">
                ${files.map((f) => html`
                    <div key=${f.id} className="rx-row" style=${{ '--rx-progress': f.progress + '%' }}>
                        <span>${iconFor(f.status)}</span>
                        <span className="rx-row__name">${f.name}</span>
                        <span className=${`rx-row__status rx-row__status--${f.status}`}>${f.status}</span>
                        <span className="rx-row__bar"><span className="rx-row__bar-fill"></span></span>
                        <span className="rx-row__pct">${Math.round(f.progress)}%</span>
                        <span className="rx-row__actions">
                            ${actionLabel(f.status) && html`<button className="rx-row__action" onClick=${() => rowAction(f)}>${actionLabel(f.status)}</button>`}
                        </span>
                    </div>
                `)}
            </div>`}
    `
}

createRoot(document.getElementById('react-root')).render(React.createElement(Uploader))

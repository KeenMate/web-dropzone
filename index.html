Web Dropzone

File upload web component with drag-drop, previews, validation, and multiple display modes

v1.0.0

Three modes, one component

Pick a mode up-front via the mode attribute — it's a hard switch that decides who renders what.

  • mode="bulk" (default) — framework owns the UI; you style via CSS variables. See Classic / Validation.
  • mode="structural" — framework owns the lifecycle; you provide HTML structure via render callbacks (including renderListWrapperCallback for tables and element-returning rows with file-row-update events). See Custom Rendering.
  • mode="headless" — framework just fires events (files-changed on rAF + granular ones); bring your own renderer or pair with satellites. See Architecture.

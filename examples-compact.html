📎 Compact & Popover

Inline summary + click-to-expand popover, custom templates, files-inside layout

Compact Display Mode

display-mode="compact" renders an inline summary line. Click it to open a popover with the full file table (icon, name, size, progress, status, remove).

Drop a few files, then click the summary to open the popover.

Summary Template (summary-template)

The summary text supports {count} and {size} placeholders for quick customization without writing JS.

Beyond placeholders

For richer summaries (pluralization rules, total size in different units, badges), use renderSummaryCallback — see the Structural Rendering page.

Popover Placement (popover-placement)

The popover positioning uses Floating UI, so it auto-flips on viewport collisions. The attribute sets the preferred initial placement.

Files-Inside Layout (files-inside)

Render the file list inside the dropzone area instead of below it. Useful when vertical space is constrained or when you want a unified container look.

Compact + many files

The popover body is independently scrollable (--dz-popover-max-height) so the compact selector stays small no matter how many files are picked.

Pick a bunch of files and watch the popover scroll.

Lit integration

A LitElement wraps a headless <web-dropzone> store, listens for files-changed, and renders its own reactive file list with lit-html templates.

LT01 · Why Lit + headless mode is a natural fit

Web-dropzone is already a custom element, so it composes inside a Lit component the same way any other element does. With mode="headless" the store stops rendering its own list — your Lit element subscribes to the files-changed event and reactivity does the rest. The native <web-dropzone-picker> satellite still handles drag/drop so you keep the polished picker UI for free.

Pattern
  • <web-dropzone mode="headless"> is the store — fires events, owns FileState, never renders.
  • <web-dropzone-picker for="…"> stays as the drag/drop surface — bind via for="".
  • Your LitElement stores @state() files, subscribes once in firstUpdated, and re-renders on every event.

LT02 · Live demo

The <lit-uploader> below uses createRenderRoot() to opt into light-DOM rendering so the satellite's for="" resolution (via document.getElementById) works without extra plumbing. Drop a few files — the list, summary line, and per-row pause/resume/retry are all driven by Lit reactive state.

LT03 · The whole component

import { LitElement, html } from 'https://esm.sh/lit@3'

class LitUploader extends LitElement {
    static properties = { files: { state: true } }

    constructor() {
        super()
        this.files = []
    }

    // Render in light DOM so <web-dropzone-picker for="…"> can resolve
    // the store via document.getElementById without piercing a shadow root.
    createRenderRoot() { return this }

    firstUpdated() {
        const store = this.querySelector('#lit-store')
        store.uploadFileCallback = simulateUpload({ durationMs: 4000 })
        store.addEventListener('files-changed', (e) => {
            this.files = e.detail.files
        })
    }

    rowAction(file) {
        const store = this.querySelector('#lit-store')
        if (file.status === 'uploading') return store.pauseFile(file.id)
        if (file.status === 'paused')    return store.resumeFile(file.id)
        if (file.status === 'error')     return store.retryFile(file.id)
    }

    render() {
        const summary = this.files.reduce((acc, f) => {
            acc[f.status] = (acc[f.status] ?? 0) + 1
            return acc
        }, {})

        return html`
            <web-dropzone id="lit-store" mode="headless" multiple max-file-count="6"></web-dropzone>
            <web-dropzone-picker for="lit-store" selector-appearance="card" label="Drop files for Lit"></web-dropzone-picker>

            ${this.files.length === 0
                ? html`<div class="lit-empty">No files yet — drop something above.</div>`
                : html`<div class="lit-list">
                    ${this.files.map(f => html`
                        <div class="lit-row">
                            <span>${iconFor(f.status)}</span>
                            <span class="lit-row__name">${f.name}</span>
                            <span class="lit-row__status lit-row__status--${f.status}">${f.status}</span>
                            <span class="lit-row__pct">${Math.round(f.progress)}%</span>
                            <span class="lit-row__actions">
                                ${actionLabel(f.status)
                                    ? html`<button class="lit-row__action" @click=${() => this.rowAction(f)}>${actionLabel(f.status)}</button>`
                                    : null}
                            </span>
                        </div>
                    `)}
                </div>`}

            <div class="lit-summary">
                <span>total <strong>${this.files.length}</strong></span>
                <span>uploading <strong>${summary.uploading ?? 0}</strong></span>
                <span>done <strong>${summary.complete ?? 0}</strong></span>
                <span>failed <strong>${summary.error ?? 0}</strong></span>
            </div>
        `
    }
}

customElements.define('lit-uploader', LitUploader)

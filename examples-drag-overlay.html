🎯 Drag Overlay

Turn any element on the page into a drop target by hovering the OS drag onto it

What it is

The overlay-target attribute points to an existing element on the page (by id or via the JS property as an HTMLElement). When the user starts dragging files anywhere on the page, the dropzone covers that element with a translucent drop overlay. Releasing the files onto the overlay adds them to the dropzone — even though the dropzone itself can be small or rendered far away in the DOM.

When to use it
  • Compact UIs: the dropzone occupies minimal space, but the user can still drop onto a large card.
  • Form integration: users drop attachments onto the form they're already filling out.
  • Full-page upload: point at document.body and the entire page becomes the drop target.

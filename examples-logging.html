🐛 Logging & Debugging

Categorized debug output with runtime control — silent by default in production

LG01 · The logging system

Built on loglevel, the dropzone exposes four log categories that can be enabled independently at any time:

  • DROPZONE:INIT — component initialization, config updates, lifecycle
  • DROPZONE:FILE — file additions, removals, validation, preview generation
  • DROPZONE:UI — DOM rendering, popover open/close, file list updates
  • DROPZONE:INTERACTION — user drag/drop, clicks, keyboard input

All categories start at silent in production builds. Flip them on at runtime via the global API or imported helpers.

LG02 · Global API (window.components['web-dropzone'])

Once the component is loaded, a global API is available for runtime control. Useful in browser DevTools or for support tooling.

// Show version + package metadata
window.components['web-dropzone'].version()
window.components['web-dropzone'].config

// Enable everything at debug level
window.components['web-dropzone'].logging.enableLogging()

// Set just one category
window.components['web-dropzone'].logging.setCategoryLevel('DROPZONE:FILE', 'debug')

// Mute everything
window.components['web-dropzone'].logging.disableLogging()

// List available categories
window.components['web-dropzone'].logging.getCategories()
// -> ['DROPZONE:INIT', 'DROPZONE:FILE', 'DROPZONE:UI', 'DROPZONE:INTERACTION']

LG04 · Import API

When you import the package directly, the same helpers are available as named exports.

import {
    enableLogging,
    disableLogging,
    setLogLevel,
    setCategoryLevel,
    LOGGING_CATEGORIES
} from '@keenmate/web-dropzone'

// All categories at debug
enableLogging()

// Or per-category
setCategoryLevel('DROPZONE:FILE', 'info')
setCategoryLevel('DROPZONE:UI',   'silent')

// In production
disableLogging()

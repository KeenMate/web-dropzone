🎨 Theming & Sizing

Three levels of customization: --base-* (cross-component), --dz-* (component), --dz-rem (global scaling)

TH01 · Three levels of theming

From broadest to most surgical:

  1. --base-* variables — shared with web-multiselect, web-daterangepicker, and other KM components. Set them on a parent and every component picks up the same theme.
  2. --dz-* variables — dropzone-only overrides for colors, radii, padding, font sizes, etc.
  3. --dz-rem scaling — single CSS variable that proportionally scales every internal dimension.

For a showcase of what's possible, see the Theme Gallery further down this page.

TH02 · Global scaling with --dz-rem

Every internal dimension is expressed as calc(N * var(--dz-rem)). Change --dz-rem once and the whole component scales — no per-variable overrides needed.

Compact (80%)

--dz-rem: 8px

Default (100%)

--dz-rem: 10px

Large (120%)

--dz-rem: 12px

<!-- One variable scales everything -->
<web-dropzone style="--dz-rem: 12px;"></web-dropzone>
Pure-Admin integration

To inherit the host page's rem, set --dz-rem: 1rem alongside html { font-size: 10px }.

TH03 · Per-variable overrides (--dz-*)

For surgical changes, override individual variables instead of --dz-rem.

web-dropzone {
    --dz-dropzone-text-font-size: 18px;
    --dz-dropzone-icon-size: 60px;
    --dz-dropzone-padding: 40px;
}

TH04 · Custom fonts via --dz-font-family

The shadow DOM inherits the host font. Set font-family directly or via --dz-font-family.

<!-- Either works -->
<web-dropzone style="font-family: 'Inter', sans-serif;"></web-dropzone>
web-dropzone { --dz-font-family: 'Inter', sans-serif; }

TH05 · Cross-component theming with --base-*

The KM web-component family shares a small set of theming variables prefixed --base-*. Set them on a parent element and every KM component below inherits the same palette.

Contract
  • Typography: --base-font-family, --base-font-size-xs|sm|base|lg (unitless multipliers), --base-font-weight-normal|medium|semibold
  • Colors: --base-accent-color[-hover|-active|-light], --base-text-color-1..4, --base-text-on-accent, --base-border-color, --base-primary-bg[-hover], --base-input-background, --base-success-color, --base-danger-color, --base-warning-color
  • Radii: --base-border-radius-sm|md|lg (unitless multipliers)

TH09 · Building a theme — recipe

Combine all three levels. Start broad with --base-*, then override --dz-* for dropzone-only touch-ups, and use --dz-rem if you need a different overall size.

.app-shell {
    /* Level 1 — cross-component palette */
    --base-accent-color: #818cf8;
    --base-text-color-1: #e2e8f0;
    --base-border-color: #334155;
    --base-input-background: #1e293b;
    --base-font-family: 'Inter', sans-serif;
}

/* Level 2 — dropzone-only tweaks */
web-dropzone {
    --dz-dropzone-border: 1px solid #d1d5db;
    --dz-dropzone-border-radius: 0;
    --dz-dropzone-min-height: 80px;
    --dz-dropzone-padding: 16px;
}

/* Level 3 — global scaling */
web-dropzone { --dz-rem: 11px; }

The other KM components inside .app-shell automatically pick up the level-1 settings.

<div class="app-shell">
    <web-dropzone></web-dropzone>
    <web-multiselect></web-multiselect>
    <web-daterangepicker></web-daterangepicker>
</div>

📝 Form Integration

Form-associated submission with real FormData and automatic form reset

FI01 · How it works

<web-dropzone> is a form-associated custom element. Set name="..." and the surrounding form sees every selected file as a real File blob — exactly like <input type="file" multiple>.

Behind the scenes
  • static formAssociated = true opts in to the form lifecycle.
  • On every selection change, the element calls internals.setFormValue(formData) with a FormData carrying each File under the configured name.
  • formResetCallback() calls clear() so form.reset() empties the selection.

FI03 · What the server sees

When this form is POSTed with enctype="multipart/form-data", the server receives each file under the attachments field — same wire format as a standard file input.

// Express.js example with multer
const multer = require('multer')
const upload = multer({ storage: multer.memoryStorage() })

app.post('/upload', upload.array('attachments'), (req, res) => {
    console.log(req.body.title)      // -> "Quarterly report"
    console.log(req.body.email)      // -> "alice@example.com"
    console.log(req.files.length)    // -> number of dropped files
    req.files.forEach(f => {
        console.log(f.originalname, f.size, f.mimetype)
    })
})
<!-- The form must use multipart encoding for file fields -->
<form action="/upload" method="post" enctype="multipart/form-data">
    <input type="text" name="title">
    <web-dropzone name="attachments" multiple></web-dropzone>
    <button type="submit">Upload</button>
</form>

FI04 · Form Reset

Native form.reset() clears the dropzone via formResetCallback(). The reset button above demonstrates this — pick a few files, hit Reset, and the selection disappears alongside the text fields.

document.getElementById('upload-form').reset()
//  ^ text inputs reset to their default value
//  ^ web-dropzone clears its file selection
